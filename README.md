# Mentor Bot

Персональный Telegram-бот — жёсткий AI-наставник. Держит на одном треке к главной цели, отслеживает ежедневный прогресс и помогает улучшать английский.

## Стек

- Python 3.11+, aiogram 3.x
- Claude API (claude-haiku-4-5) — диалог с памятью
- Whisper API — транскрипция голосовых сообщений
- SQLite (aiosqlite)
- APScheduler — ежедневные уведомления
- Railway — хостинг (polling)

## Установка

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполнить `.env`:

```
TELEGRAM_BOT_TOKEN=
ANTHROPIC_API_KEY=
OPENAI_API_KEY=
TELEGRAM_USER_ID=
DATABASE_PATH=mentor.db
TIMEZONE=Europe/Amsterdam
```

## Запуск

```bash
python bot.py
```

## Команды

| Команда | Действие |
|---------|----------|
| /start | Онбординг, фиксация главной цели |
| /status | Streak, прогресс недели, главная цель |
| /week | Недельная сводка |
| /ideas | Список припаркованных идей |
| /goal | Показать/изменить главную цель |

## Деплой на Railway

1. Создать проект на railway.app, подключить GitHub репо
2. Добавить переменные окружения из `.env.example`
3. SQLite хранить на persistent volume (`/data/mentor.db`)
4. Запуск как worker (polling), не web-сервис

## Квест дня (Telegram Mini App)

Игровой распорядок дня внутри бота: живой план дня, видео с фокус-таймером, TheorieExamen.nl, тренировки, Duolingo, награда дня, вес и рабочие веса.

### Запуск на Railway
1. Settings → Networking → **Generate Domain**. Получишь адрес вида `https://optimus-production.up.railway.app`.
2. Variables → добавить `WEBAPP_URL` = этот адрес со слешем в конце.
3. Чтобы база не стиралась при деплое: добавить Volume с mount path `/data` и поставить `DATABASE_PATH=/data/mentor.db`.
4. Деплой. В боте появится кнопка меню «Квест» и команда `/quest`.

### Что понимает бот
- фото с тренировки, скрин TheorieExamen.nl, скрин Duolingo, скрин загрузки видео: проверка через Claude и отметка квеста
- ссылка на YouTube: видео засчитано (вторая ссылка за день: бонусное второе видео)
- `покурил`: отметка травы. Награда дня открывается, когда закрыты 4 главных дела: видео, тренировка, теория, Duolingo
- `вес 82.5`: взвешивание
- `добавь: отвезти Audi 10:00 1ч; письмо в UWV`: свои дела на сегодня. Время делает дело якорем, длительность по умолчанию 30 мин
- `завтра: дело1; дело2`: план на завтра, тот же формат

День считается живым планом: у каждого дела есть длительность, всё несделанное раскладывается от текущего момента и обтекает якоря (дела с точным временем, вечер с 22:45). Бот сверяется с планом каждые 5 минут и пишет: «пора», «идёт дольше плана», «не влезает до отбоя». Дота просто для свободного времени, после видео, блоком 45 минут. Плюс 22:30 итог дня, пн 08:10 взвешивание.

Наказания: провал = день без видео. На следующий день −100 XP за провал, долг (второе видео) и штраф €5 в safemoney со скрином Trading 212. Пока долг и штраф не закрыты, награда дня и Дота закрыты. Долг не копится: максимум одно лишнее видео.
